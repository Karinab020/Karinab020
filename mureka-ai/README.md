# 🎵 Mureka AI - Gerador de Música com IA

Um aplicativo web moderno para geração de música usando Inteligência Artificial, inspirado no Mureka AI. Transforme suas ideias em música única em segundos!

## ✨ Funcionalidades

- 🎼 **Geração de Música por IA**: Descreva sua música ideal e nossa IA criará uma trilha única
- 🎵 **Player de Música Avançado**: Controles completos com visualização de áudio em tempo real
- 📚 **Biblioteca Pessoal**: Organize e acesse todas suas criações musicais
- 🔍 **Busca e Filtros**: Encontre rapidamente suas músicas por gênero, humor ou título
- 📱 **Design Responsivo**: Interface moderna que funciona em qualquer dispositivo
- 🎨 **UI/UX Moderna**: Design dark com gradientes e efeitos visuais atraentes

## 🚀 Tecnologias Utilizadas

- **React 18** - Framework principal
- **TypeScript** - Tipagem estática
- **Tailwind CSS** - Estilização moderna
- **Vite** - Build tool rápido
- **Lucide React** - Ícones modernos
- **Radix UI** - Componentes acessíveis

## 🛠️ Instalação e Execução

### Pré-requisitos
- Node.js 16+ 
- npm ou yarn

### Instalação

1. Clone o repositório:
```bash
git clone <url-do-repositorio>
cd mureka-ai
```

2. Instale as dependências:
```bash
npm install
```

3. Execute o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra seu navegador em `http://localhost:5173`

## 📖 Como Usar

### 1. Gerar Música
- Digite uma descrição detalhada da música que você deseja
- Selecione o gênero musical (pop, rock, electronic, etc.)
- Escolha o humor/mood (happy, sad, energetic, etc.)
- Defina a duração desejada
- Clique em "Gerar Música" e aguarde a IA processar

### 2. Reproduzir Música
- Clique em qualquer música gerada para iniciar a reprodução
- Use os controles do player para pausar, avançar ou retroceder
- Ajuste o volume conforme necessário
- Acompanhe o progresso com a barra de tempo

### 3. Gerenciar Biblioteca
- Todas suas músicas ficam salvas na biblioteca
- Use a busca para encontrar músicas específicas
- Filtre por gênero ou organize por data/título
- Curta suas favoritas e baixe quando quiser
